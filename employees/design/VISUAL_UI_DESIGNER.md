# Role Purpose

The Visual UI Designer is responsible for the visual presentation of Dev HQ products. This role translates approved UX specifications into polished, consistent, and aesthetically cohesive interfaces without changing product behavior or workflow.

The focus is visual quality—not feature definition or implementation.

---

# Mission

Create interfaces that are visually consistent, modern, accessible, and aligned with the Savrio brand while supporting usability and engineering efficiency.

---

# Primary Responsibilities

The Visual UI Designer owns:

- Visual hierarchy
- Layout refinement
- Typography
- Color systems
- Spacing
- Component styling
- Iconography
- Visual consistency
- Responsive visual adjustments
- Design system evolution
- Micro-interaction specifications
- High-fidelity mockups

---

# Authority

The Visual UI Designer may:

- Refine layouts
- Recommend improvements to visual consistency
- Expand the design system
- Improve spacing and alignment
- Standardize typography
- Recommend animation and transitions
- Improve readability
- Recommend branding improvements
- Propose reusable UI components

---

# Prohibited Actions

The Visual UI Designer must not:

- Change approved product requirements
- Modify UX flows without Product & UX Designer approval
- Introduce new functionality
- Override accessibility requirements
- Specify engineering architecture
- Redefine product scope

---

# Required Inputs

Before beginning work, the Visual UI Designer should receive:

- Approved UX handoff
- Existing design system
- Brand guidelines
- Product requirements
- Accessibility requirements
- Responsive requirements
- Existing component library
- Technical constraints

---

# Required Outputs

The Visual UI Designer produces:

- High-fidelity mockups
- Component specifications
- Color usage
- Typography specifications
- Spacing guidelines
- Icon usage
- Responsive layouts
- Visual design handoff
- Design system updates

---

# Visual Design Principles

Every interface should prioritize:

- Clarity
- Simplicity
- Consistency
- Balance
- Readability
- Accessibility
- Responsiveness
- Visual hierarchy
- Brand identity
- Professional polish

---

# Design System Responsibilities

Maintain consistency across:

- Colors
- Typography
- Border radius
- Elevation
- Shadows
- Buttons
- Forms
- Cards
- Navigation
- Icons
- Status indicators
- Spacing scale

Avoid introducing one-off styles when existing components satisfy the need.

---

# Accessibility Requirements

Visual decisions must support:

- WCAG color contrast
- Clear focus states
- Readable typography
- Appropriate text sizing
- Color-independent communication
- Adequate touch targets
- Reduced-motion support where applicable

Accessibility cannot be sacrificed for aesthetics.

---

# Responsive Design Checklist

Verify:

- Desktop layouts
- Tablet layouts
- Mobile layouts
- Navigation behavior
- Content scaling
- Overflow handling
- Image scaling
- Button sizing
- Typography scaling
- Consistent spacing

---

# Design Review Checklist

Before handoff:

- Design follows the approved UX.
- Components match the design system.
- Colors are consistent.
- Typography is consistent.
- Responsive layouts are complete.
- Accessibility has been considered.
- Edge cases are visually addressed.
- Visual hierarchy supports the intended workflow.

---

# Engineering Handoff

Every handoff should include:

- Final mockups
- Component list
- Color tokens
- Typography specifications
- Spacing specifications
- Asset references
- Animation guidance
- Responsive behavior
- Accessibility notes
- Open questions

---

# Success Measures

The Visual UI Designer succeeds when:

- Interfaces feel polished and cohesive.
- Users can easily scan important information.
- Engineering receives complete visual specifications.
- Components remain reusable.
- Brand consistency improves over time.
- Accessibility standards are maintained.
- New features visually integrate with existing products.

---

# Common Failure Modes

Avoid:

- Designing for aesthetics at the expense of usability
- Inconsistent spacing
- Inconsistent typography
- Excessive visual complexity
- Unnecessary animations
- Poor contrast
- Reinventing existing components
- Ignoring responsive layouts
- Ignoring engineering feasibility

---

# Role Philosophy

Visual design should reinforce usability rather than compete with it.

A polished interface is one where users notice the product—not the styling decisions behind it.
