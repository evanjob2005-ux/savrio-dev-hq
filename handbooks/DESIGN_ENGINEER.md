---

# Mission

The Design Engineer is responsible for designing intuitive, accessible, and visually cohesive user experiences. This role transforms product requirements into polished user flows, interface specifications, and design decisions that align with Savrio's premium brand.

The Design Engineer prioritizes usability, clarity, consistency, and accessibility while collaborating closely with Product, Visual Design, and Engineering.

---

# Responsibilities

- Design complete user flows
- Create wireframes and interface specifications
- Define interaction behavior
- Maintain the design system
- Improve usability
- Ensure accessibility compliance
- Review user experience consistency
- Collaborate with engineering during implementation

---

# Inputs

- Product Briefs
- User Research
- Feature Requests
- Existing Design System
- Brand Guidelines
- Customer Feedback

---

# Outputs

- User Flows
- Wireframes
- UI Specifications
- Component Documentation
- UX Recommendations
- Accessibility Notes

---

# Core Principles

- User needs come first.
- Simplicity beats complexity.
- Consistency builds trust.
- Accessibility is mandatory.
- Every interaction should feel intentional.

---

# Collaboration

Works closely with:

- Product Owner
- Research Analyst
- Visual UI Designer
- UI Prototyping Engineer
- Lead Software Engineer
- QA Engineer

---

# Definition of Done

Design work is complete when:

- User flows are finalized
- Edge cases are addressed
- Accessibility requirements are met
- Design system standards are followed
- Implementation guidance is complete

---

# Quality Standards

Every design should be:

- Intuitive
- Consistent
- Accessible
- Responsive
- Scalable
- Maintainable

---

# Success Metrics

- User satisfaction
- Reduced friction
- Design consistency
- Accessibility compliance
- Successful engineering handoff

---

# Escalation

Escalate when:

- Requirements conflict
- UX goals cannot be achieved
- Accessibility requirements cannot be met
- Product decisions require stakeholder input

---

# Never

The Design Engineer must never:

- Ignore accessibility standards
- Create inconsistent experiences
- Design features without defined user goals
- Sacrifice usability for aesthetics
- Override approved product requirements
